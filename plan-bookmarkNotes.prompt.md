## Plan: Bookmark Notes Persistence

Add nullable bookmark notes end-to-end by extending favorites storage, threading note data through domain/repository, and updating UDF events/state so note capture/edit flows are explicit (not hidden inside a toggle). This preserves notes across restarts, shows notes on the bookmarks screen, and guarantees note deletion when unbookmarking.
